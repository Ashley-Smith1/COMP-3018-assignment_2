## About the Project

For this assignment, I created a Support Ticket API using Node.js, Express, and TypeScript.

The API allows users to create, view, update, and delete tickets. It also calculates how urgent a ticket is based on its priority and age.

## Features

- Create, view, update, and delete tickets
- Calculate ticket urgency
- Check if the API is running
- Handle invalid requests

## How to Run

Install dependencies:

npm install

Start the server:

npm run dev

The API runs at http://localhost:3000

## Testing

I used Bruno to test my API requests and Jest with Supertest for automated testing.

Run tests:

npm test

Check linting:

npm run lint

Build the project:

npm run build

All 12 automated tests passed.
